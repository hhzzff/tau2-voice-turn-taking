# Open-model adapter integration

Use `OpenModelConfig(model="salmonn" | "minicpm")` before starting a model
runtime. `tick_duration_seconds` may be supplied explicitly but must match the
native duration. `tick_duration_ms` is 80 or 1000 respectively. `model_identity`
fixes SALMONN to before-SFT checkpoint-44000 and MiniCPM to MiniCPM-o-4.5.
These defaults live in `tau2.config`.

## Adapter

Implement the existing `DiscreteTimeAdapter` contract. Construct its base with
`tick_duration_ms=config.tick_duration_ms`, `pacing=config.pacing`, and the
external audio format (normally telephony μ-law, 8000 Hz, mono).

- `connect` starts/resets a conversation; `disconnect` releases runtime state.
- `run_tick` bridges sync to `_async_run_tick`; implement `_execute_tick` and
  `_flush_pending_tool_results`, without replacing the template.
- `_execute_tick` delivers only this tick's audio to the persistent runtime and
  waits for completion, regardless of wall duration. It must not use an audio
  duration as an inference timeout. A separate operational timeout may raise
  an explicit error.
- Append generated audio in external format to `result.agent_audio_chunks`.
  The template caps playback and carries excess forward. Always consume new
  user audio, including while queued model output is playing.
- Use `StreamingTelephonyConverter` for native runtime sample rates, retaining
  conversion state across chunks. Reset conversion and model state on a new
  conversation. No complete future user waveform may be preloaded.
- The template records `computation_duration_seconds` before optional wall
  pacing. `pacing="frozen"` skips this sleep. API adapters default to realtime
  and keep their existing behavior.
- `get_played_agent_audio()` pads short output with silence to one tick.
  Generated bytes and played bytes are distinct evidence.
- Tool calls are outside MVP scope; reject unsupported tools explicitly.

A subprocess or remote worker can implement inference behind this boundary;
its Python version and model dependencies need not match the controller.
Transport details do not change tick semantics.

## Orchestrator and demo

Use `FullDuplexOrchestrator(..., tick_duration_seconds=config.tick_duration_seconds,
pacing=config.pacing)` with existing streaming participants. It snapshots both
previous chunks before stepping either participant. Each completed `step()`
adds one trajectory tick; use `tick_duration_seconds` for simulated audio time
and `wall_clock_duration_seconds` for actual step computation. The orchestrator
never sleeps; frozen mode also disables its faster-than-realtime warning.

Initialization preserves the existing initial trajectory tick. Include that
initial audio interval consistently in both WAV tracks and timeline indices.
Do not silently omit the first user chunk. The existing initialization timing
field measures initial record construction rather than model loading or the
initial user generation; record startup costs separately when needed.

Validate native duration through `OpenModelConfig`, then pass the same duration
to user chunk sizing, adapter and orchestrator. Use `AudioNativeConfig` for the
existing user timing settings when constructing the user simulator. Positive
subsecond threshold rounding is addressed by the scenario/user integration
ticket. The open-model config intentionally does not enable a partial local
provider in the API evaluation CLI before a real adapter exists.

## Native worker launch and transport

`tau2.voice.audio_native.open_model.adapter.OpenModelAdapter(config,
runtime_config=None, transport=None)` implements the public lifecycle. Native
assets default to the explicit manifests in `tau2.config`; SALMONN always
selects the agreed before-SFT checkpoint by default. The registry factory
`open_model_agent` (`create_open_model_agent`) takes `open_model_config`,
`runtime_config`, and `transport` keyword arguments and wraps this adapter in
`DiscreteTimeAudioNativeAgent`. Tools are rejected.

For Merlin, run the native Python executable with
`scripts/open_model_workers/worker.py --model minicpm --mailbox /shared/run/mailbox
--idle-timeout 1800` (or `--model salmonn`). Keep each model in its own mailbox.
The controller passes `MailboxTransport('/shared/run/mailbox')` from
`tau2.voice.audio_native.open_model.transport`. `ready.json` records that the
server is listening, not that weights have loaded. Loading occurs on connect.
Create mailbox `STOP` to exit; idle timeout also releases the worker. Each
controller session has a UUID directory. Requests/responses use monotonic
sequence names and atomic rename. A `closed` marker abandons a failed session.
Do not reuse a run's mailbox for a different worker process.

Without a supplied transport, an isolated native subprocess exchanges JSON
lines on stdin/stdout. Native model logging is redirected to stderr. Separate
operational timeouts default to 1800 seconds and fail visibly; they never
advance simulation time or fabricate audio. All audio wire payloads are
little-endian mono PCM16 encoded in `audio_pcm16_b64`. Input is always 16kHz,
with exactly 1280 or 16000 samples. Responses contain `sample_rate`, `text`,
and `events`. The model interface is `connect(config, system_prompt) ->
provenance`, `step(pcm16_bytes) -> response`, and `disconnect()`. It is Python
3.10 compatible and imports no controller packages.

The causal telephony resampler's initial missing interpolation sample is
extended from the last available sample once at the first input boundary;
conversion filter state then persists across ticks. This does not read future
audio. Native-generated sample count and text are retained as events separately
from played/capped audio. No annotation-derived forced interruption is enabled.
