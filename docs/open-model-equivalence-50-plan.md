# 开源模型三组对照：每组50个样本

状态：MiniCPM、Freeze-Omni、Moshi各150次批量正在运行；SALMONN单次预检重现共同TTS错误，未启动其50次批量。

## 三种处理路径

- A：原生直连，按原生输入块结束时间发送，收到可用音频即播放。
- B：异步编排，100ms发送/收集窗口，按会话起点的绝对时间推进。
- C：异步编排，发送/收集窗口等于模型原生块宽，同样按绝对时间推进。

C不等待本步推理结束；窗口到期就进入下一窗口。原生块宽：MiniCPM1000ms、
Freeze-Omni160ms、Moshi80ms、SALMONN80ms。不能把旧frozen组当作C。

## 样本单位

用户已确认：同一固定音轨独立重复50次，估计固定输入条件下的运行波动和
编排差值，不据此推断跨输入泛化。每个模型为50个配对三元组，即每组50次、
总计150次。三个当前可运行模型共450次；SALMONN另行预检。
每个三元组使用相同GPU、权重、输入、seed和控制策略，采用均衡交错的三组
执行顺序；每次独立重置会话，保存GPU UUID、版本与完整配置。Moshi保持已
验证的原服务器预热；其他模型的冷启动条件保持一致并单独报告，不混入或
隐去冷启动异常值。重复次数不能自动保证100ms精度或覆盖不同对话内容。

## 汇总

按模型分别报告，不跨模型混合均值：

- 请求次数、成功数、失败数及原因、可比较的配对数。
- 每次输入/输出PCM、文本和状态是否一致。
- 首次开口及匹配语音边界的有符号配对差、绝对误差。
- 均值、中位数、P90/P95、最大值、超过100ms比例；保留全量散点。
- 配对差均值的95%区间，并明确50次重复下尾部分位数的不确定性。
- 活动区间缺失/数量不一致单列，不当作0误差；不以平均误差抵消提前和延后。
- 累计时钟漂移与原生推理耗时单列，避免混淆成同一延迟。
